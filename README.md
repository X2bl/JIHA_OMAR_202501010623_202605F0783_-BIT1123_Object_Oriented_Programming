## How to Run the Projects

1. Install a Java Development Kit (JDK), version 17 or later.
2. Open a terminal in the tutorial folder you want to run.
3. Compile the Java source files, for example:

   ```bash
   javac *.java
   ```

4. Run the class that contains `main`, for example:

   ```bash
   java Main
   ```

For Week 10, compile and run the GUI as follows:

```bash
cd week10
javac Questions.java QuizBattleGUI.java
java QuizBattleGUI
```
