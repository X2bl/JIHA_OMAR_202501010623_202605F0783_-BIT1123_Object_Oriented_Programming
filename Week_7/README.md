# Week 7 - Smart Home Appliance Management System

This activity demonstrates abstraction.

- `Appliances.java` contains the abstract `Appliance` class.
- `WashingMachine` and `Refrigerator` inherit from `Appliance`.
- `Main.java` creates the objects and runs their methods.

The program displays the brand, turns the power on, operates the appliance,
and turns the power off.
